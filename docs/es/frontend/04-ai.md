# Integración de IA (Genkit)

El frontend integra **Google Genkit** con **Gemini 2.5 Flash** para analizar logs de servidores y generar sugerencias de solución de problemas.

## Configuración (`src/ai/genkit.ts`)

```typescript
import {genkit} from 'genkit';
import {googleAI} from '@genkit-ai/google-genai';

export const ai = genkit({
  plugins: [googleAI()],
  model: 'googleai/gemini-2.5-flash',
});
```

- Usa el plugin `@genkit-ai/google-genai` con el modelo `gemini-2.5-flash`.
- La API key se configura en el backend (`geminiApiKey` en Settings del panel).

## Flujos (Flows)

### `summarizeServerAlerts` (`src/ai/flows/summarize-server-alerts.ts`)

Resume logs complejos en texto claro y conciso.

- **Input:** `{ logs: string }` — logs o alertas del servidor.
- **Output:** `{ summary: string }` — resumen conciso en lenguaje natural.
- **Prompt:** Extrae información crítica, identifica problemas potenciales y los presenta claramente.

### `generateTroubleshootingTips` (`src/ai/flows/generate-troubleshooting-tips.ts`)

Genera sugerencias de solución y causas raíz basadas en un resumen de alerta.

- **Input:** `{ alertSummary: string }` — resumen de alerta o problema.
- **Output:** `{ suggestions: string[], rootCauses: string[] }` — pasos accionables y causas potenciales.
- **Prompt:** Actúa como administrador de sistemas experto, proporcionando sugerencias inmediatas.

## Integración en la UI

Ambos flujos se ejecutan desde el componente `ai-summary.tsx` en `features/servers/[id]/`:

1. El usuario hace clic en "AI Analyze" en la vista del servidor.
2. Se envían los logs recientes al backend (`POST /api/ai/analyze` o `POST /api/servers/:serverId/ai/analyze`).
3. El backend invoca el endpoint de Gemini y devuelve el análisis estructurado.
4. El resultado se muestra en la UI con resumen, causas raíz y sugerencias.

## Requisitos

- `geminiApiKey` configurada en Settings del panel.
- Conexión a internet desde el servidor para alcanzar `generativelanguage.googleapis.com`.
