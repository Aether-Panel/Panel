# Términos y Condiciones de Servicio

## Introducción

Estos Términos de Servicio rigen tu uso de Aether Panel. Al acceder o utilizar nuestro servicio, aceptas estar sujeto a estos términos. Si no estás de acuerdo con alguna parte de los términos, no puedes acceder al servicio.

Aether Panel es un proyecto open source que opera bajo principios diferentes a otros paneles en el mercado. Estos términos reflejan nuestra filosofía de ser un panel verdaderamente gratuito, que escucha a la comunidad y no monetiza funciones básicas.

Al usar Aether Panel, reconoces que es software open source proporcionado "tal cual" sin garantías comerciales. El panel principal es gratuito y open source — los únicos complementos que podrían tener costo son integraciones con software de código cerrado de terceros (como WHMCS), para cubrir licencias y mantenimiento.

## Aceptación de los Términos

Al acceder y usar Aether Panel, aceptas:

- Estar legalmente vinculado por estos términos
- Cumplir con todas las leyes y regulaciones aplicables
- Ser responsable de tu uso del servicio

## Naturaleza Open Source

Aether Panel es software open source distribuido bajo su licencia correspondiente. Al usar Aether Panel, reconoces y aceptas:

Esta filosofía es fundamental para Aether Panel. El panel principal siempre será gratuito y open source.

### Sin Garantías Comerciales

El software se proporciona "tal cual" sin garantías de ningún tipo, expresas o implícitas. No ofrecemos soporte técnico comercial ni garantizamos que el software funcionará sin errores.

### Panel Principal Gratuito

El núcleo del panel es y será siempre completamente gratuito y open source (Apache 2.0). Todas las funciones esenciales del panel están disponibles sin costo. Complementos para integraciones con software de código cerrado (como WHMCS) pueden tener costo para cubrir licencias y mantenimiento.

### Comunidad Primero

Las decisiones de desarrollo se basan en las necesidades de la comunidad. El panel principal siempre será gratuito y abierto.

### Sin Paywalls en el Panel

Nunca pondremos funciones del panel principal tras un paywall. El panel es y será siempre gratuito. Solo integraciones con software de código cerrado de terceros podrían tener costo.

## Módulos de Pago e Integraciones

El panel principal de Aether Panel es y será siempre 100% gratuito y open source (Apache 2.0). Sin embargo, pueden existir módulos de integración con software de terceros que tengan un costo asociado.

Actualmente estamos desarrollando un módulo de integración con WHMCS (plataforma de facturación y automatización). WHMCS es un software de código cerrado que requiere licencia paga, por lo que el módulo tiene costos asociados:

- WHMCS es software propietario — requiere licencia paga para desarrollo, pruebas y mantenimiento
- El módulo requiere mantenimiento continuo para garantizar compatibilidad con actualizaciones de WHMCS
- Los fondos se utilizan para cubrir costos de infraestructura, licencias y desarrollo
- No tiene fines de lucro — se venderá al precio más bajo posible

### Importante

El módulo WHMCS es un complemento opcional. No necesitas comprarlo para usar el panel. El panel principal, todas sus funciones y el código fuente permanecen 100% gratuitos y open source. Nunca pondremos funciones del panel tras un paywall. Si en el futuro existieran otros módulos para integraciones con software de código cerrado, seguirían la misma política.
