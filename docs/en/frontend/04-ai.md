# AI Features (Overview)

Aether Panel uses **Google Gemini** (`gemini-3.8-flash`) to help server owners understand what is happening with their servers. All calls to Gemini are made by the **panel backend**; the frontend only calls the panel API and never sees the API key. There is no AI SDK in the frontend.

How to use the assistant as a server owner is explained in the user guide [AI assistant](../features/ai-assistant.md); this page covers the interface side. Endpoints, request and response formats, limits and prompt safety are in [08. AI in detail](./08-ai-detailed.md).

## The three features

| Feature | Where | Endpoint |
|---|---|---|
| **Server assistant** | "Assistant" button in the server header, opens a side panel with a chat. With the file tools on it can work with the server's files and asks before changing them (agent mode) | `POST /api/servers/:id/ai/chat`, `POST /api/servers/:id/ai/chat/confirm` |
| **AI console analysis** | Card under the console: lists recent lines that look like errors and explains the selected ones | `POST /api/servers/:id/ai/analyze` |
| **Explain a crash** | "Explain with AI" in the crash report dialog (opened from the crash banner above the console or from the crash history in the Overview tab) | `POST /api/servers/:id/ai/analyze` with `exitCode` |

All three require the `server.console` permission on the server and answer in the viewer's interface language (English or Spanish). Agent mode also needs `server.files.view` (and `server.files.edit` for changes); see [AI assistant: working with files](../features/ai-agent.md).

## Configuration

| Setting | Key | Default | Where |
|---|---|---|---|
| Gemini API key | `panel.settings.geminiApiKey` | empty | Settings › General |
| Turn the AI log analysis off | `panel.settings.hideAiAnalysis` | `false` | Settings › General |
| Let the assistant work with server files | `panel.settings.aiFileTools` | `true` | Settings › General |

- Environment variables follow the general rule (`SKYPANEL_` + key in upper case with dots replaced by `_`): `SKYPANEL_PANEL_SETTINGS_GEMINIAPIKEY`, `SKYPANEL_PANEL_SETTINGS_HIDEAIANALYSIS`, `SKYPANEL_PANEL_SETTINGS_AIFILETOOLS`.
- Without a key the endpoints answer `400` ("Gemini API Key is not configured") and the UI shows a "not configured" message.
- `hideAiAnalysis` turns the log analysis off for every user: the console and the crash dialog read it from the public config (`GET /api/config`, field `hideAiAnalysis`, through `useConfig()`) and hide the "AI console analysis" card and "Explain with AI"; `/ai/analyze` also answers `403` `ErrAIAnalysisDisabled`. The assistant button (chat) stays available.
- `aiFileTools` is not published in `GET /api/config`: the interface does not need it, because the chat answer itself says whether the assistant worked with files (`steps`, `pending`). The switch is in the **Artificial intelligence** section of Settings › General, read from `GET /api/settings` (an unset value counts as on).
- The panel host needs outbound HTTPS access to `generativelanguage.googleapis.com`.
- A key can be created in [Google AI Studio](https://aistudio.google.com/apikey).

## Privacy

Console lines, crash logs and server context are sent to Google's Gemini API when a user asks for an analysis or chats with the assistant, and in agent mode also the content of the files the assistant reads; nothing is sent otherwise. See the [privacy notice](../general/privacy.md) for the panel's general data handling.
