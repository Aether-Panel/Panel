# AI Integration (Genkit)

The frontend integrates **Google Genkit** with **Gemini 2.5 Flash** to analyze server logs and generate troubleshooting suggestions.

## Configuration (`src/ai/genkit.ts`)

```typescript
import {genkit} from 'genkit';
import {googleAI} from '@genkit-ai/google-genai';

export const ai = genkit({
  plugins: [googleAI()],
  model: 'googleai/gemini-2.5-flash',
});
```

- Uses the `@genkit-ai/google-genai` plugin with the `gemini-2.5-flash` model.
- The API key is configured in the backend (`geminiApiKey` in Panel Settings).

## Flows

### `summarizeServerAlerts` (`src/ai/flows/summarize-server-alerts.ts`)

Summarizes complex logs into clear and concise text.

- **Input:** `{ logs: string }` — server logs or alerts.
- **Output:** `{ summary: string }` — concise summary in natural language.
- **Prompt:** Extracts critical information, identifies potential issues, and presents them clearly.

### `generateTroubleshootingTips` (`src/ai/flows/generate-troubleshooting-tips.ts`)

Generates troubleshooting suggestions and root causes based on an alert summary.

- **Input:** `{ alertSummary: string }` — alert or issue summary.
- **Output:** `{ suggestions: string[], rootCauses: string[] }` — actionable steps and potential causes.
- **Prompt:** Acts as an expert system administrator, providing immediate suggestions.

## UI Integration

Both flows are executed from the `ai-summary.tsx` component in `features/servers/[id]/`:

1. The user clicks "AI Analyze" in the server view.
2. Recent logs are sent to the backend (`POST /api/ai/analyze` or `POST /api/servers/:serverId/ai/analyze`).
3. The backend invokes the Gemini endpoint and returns the structured analysis.
4. The result is displayed in the UI with a summary, root causes, and suggestions.

## Requirements

- `geminiApiKey` configured in Panel Settings.
- Internet connection from the server to reach `generativelanguage.googleapis.com`.
