# Política de Seguridad

> **Nota**: Aether Panel es el nombre oficial del proyecto. **SkyPanel** es el nombre en clave (codename) utilizado en el código fuente. Versión actual: **1.0.1**.

## Versiones Soportadas

Solo ofrecemos actualizaciones de seguridad para la última versión estable del panel.

| Versión | Soportada |
| :--- | :--- |
| 1.0.x | Sí |
| < 1.0 | No |

## Reportar una Vulnerabilidad

Si descubre una vulnerabilidad de seguridad en Aether Panel, le pedimos que nos informe de inmediato.

### Proceso de Reporte

1.  **No divulgue públicamente** la vulnerabilidad hasta que haya sido corregida.
2.  Envíe un correo electrónico a `security@aetherpanel.es` con los detalles técnicos.
3.  Incluya pasos para reproducir el problema y, si es posible, una prueba de concepto.

Nuestro equipo de seguridad revisará el informe y responderá en un plazo de 48 horas.

### Recompensas

Actualmente no ofrecemos un programa de recompensas monetarias (bug bounty), pero acreditaremos públicamente a los investigadores que reporten vulnerabilidades de manera responsable en nuestras notas de lanzamiento.

| Version | Supported          |
| ------- | ------------------ |
| 3.x.y   | :white_check_mark: |
| 2.x.y   | :white_check_mark: |
| 1.x.y   | :x:                |
| 0.x.y   | :x:                |

## Reporting a Vulnerability

Reporting sensitive information may be done by submitting a request on https://github.com/aetherpanel/aetherpanel/security/advisories?state=published

Reports which do not contain a valid subject or description will be ignored.
